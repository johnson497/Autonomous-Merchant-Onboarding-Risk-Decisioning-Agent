# 🛡️ Autonomous Merchant Onboarding & Risk Decisioning Agent

An end-to-end agentic AI solution designed for payment gateway merchant verification, leveraging **LangGraph** for workflow orchestration, **Scikit-Learn (Random Forest)** for risk scoring, and **SHAP (Explainable AI)** for transparent decision attributions.

---

## 📌 Architecture & Features

* **Agentic Orchestration (LangGraph)**: Multi-node workflow executing web scraping, policy extraction, and risk assessment automatically.
* **Risk Engine**: Machine learning model evaluating website compliance, domain features, and industry vertical risk metrics.
* **Explainable AI (SHAP)**: Provides local factor attributions to give reviewers transparent insight into why a merchant was approved, flagged, or rejected.
* **Interactive UI (Streamlit)**: Real-time decision dashboard displaying agent outputs and XAI breakdowns.
